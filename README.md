# 📝 Khaata App / Notes Manager

A foundational CRUD (Create, Read, Update, Delete) application built using Node.js, Express, and the core `fs` module. 

This project was developed strictly as a learning milestone to master server-side file handling, dynamic routing, and EJS templating before transitioning to industrial databases like MongoDB.

## 🚀 Features
* **Create:** Write and save new notes directly to the local server storage.
* **Read:** Dynamically fetch and read saved notes.
* **Update:** Rename existing note files.
* **Delete:** Permanently remove notes from the server.
* **UI:** Styled with modern Glassmorphism using Tailwind CSS.


## 💻 Tech Stack
* **Backend:** Node.js, Express.js
* **Storage:** Local File System (`fs` module)
* **Frontend:** EJS (Embedded JavaScript), Tailwind CSS (via CDN)
